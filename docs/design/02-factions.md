# 拆招 — 门派谱（M2.5 · 基础 pass）

- **用途**：M3 门派 hub 关系系统 / NPC 出身 / 招牌招落地的身份底座。深度门派史/门人小传留 M3–M4 `chinese-novelist`。
- **一致性约束**：严格对齐 T1 `01-world-bible.md`（地理 8 区 / 五势叙事名锐金·盘根·厚土·流水·烈火 / 三性格江湖身份名宿·狂客·妖人 / 道统之争）与 design spec §4（每门派一套自洽身份：架势偏好 + 招牌招族 + AI 风格）。
- **机制约束**：招牌招式族的**机制概念**只复用现有 `Technique.Type`（STRIKE/FEINT/MOVE/STANCE_SWITCH/SPECIAL）+ `RangeBand`（CLOSE/MID/FAR）+ `Resolver`/`Opening`/`Morale` 字段；**不发明新 Type / 新字段**。门派 NPC 默认性格映射现有 `brain/brute/trick` 三工厂；混合性格明确标 **M3+ 扩展**，M2.5 不实现。
- **命名说明**：门派正式名为本文定稿；代码 enum（`Stance.Id`/`AIPersonality` 工厂）一律不改，M3 落地 `display_name` 时引用本文。

---

## 一句话

残照江湖不是一家独大，而是**七派并立、一教为祸**的格局：七派各执一势之偏（专修锐金、或盘根、或流水……），唯**镜照门**修五势圆融，故成众矢之的；血衣教以"势有尊卑"为号，欲统江湖，灭镜照、夺真解——七派或附、或抗、或中立，主角闯荡其间，读招破势、重立残照。

> spec §4 核心特色落地：**不是 1 个门派，而是整个江湖门派谱**。每门派一套自洽身份（专属架势偏好 + 招牌招族 + AI 风格），玩家出身其一、仇派是另几个、可招募败将混血别派——build 空间 + 重玩性 + 叙事厚度一体。

## 总览：8 门派（7 江湖派 + 1 仇派）

> 编号 F1–F7 为江湖门派（玩家可出身 / 可招募 / 可为敌），F8 为仇派血衣教。每派身份差异鲜明——架势偏好、招牌招、性格三者组合无重复。

## 各门派详节

### F1. 镜照门（主角出身派 · 重建形态）

**1. 名称 + 一句话身份**
**镜照门**——修"五势圆融、心眼读万象"的中立隐门，主角亡师明镜先生所创；一夜被血衣教屠成白地，主角为唯一遗孤，以"重立残照"为己任。江湖代号"**遗照**"（玩家自定姓名，叙事即剪影）。

**2. 架势偏好**
**唯一修全五势的门派**（ALL：METAL/WOOD/EARTH/WATER/FIRE），不偏不倚，以**厚土 EARTH（Role NEUTRAL）**为枢纽流转其余四势。叙事理由（T1 维度 5）：镜照门祖训"势非形，乃意。五势者，五种观天地之道"——五势圆融即不执一偏，这正是其被血衣教（信"势有尊卑"）视为异端的道统根由。

**3. 招牌招式族**
- **架势流转**（→ `STANCE_SWITCH`）：在 5 势间快速流转，以"占克势"为读招核心——预判对手切势，提前流转到克制势。机制上 = 现有 `TechniqueKit.switch_to(s)` 的密集使用，不发明新机制；叙事上 = "心眼读势，圆转无端"。
- **反制打击**（→ `STRIKE`）：占克势后的命中打击，复用 `Resolver` 的 `counter_bonus_damage`/`counter_bonus_opening`（克制方增伤造破绽）——镜照门招牌不是"招本身强"，而是"读得准所以克制多"。

**4. AI 性格映射**
**brain（智将 / 老谋深算的名宿）**。镜照门以"心眼"立派，NPC 默认死磕 L2 玩家建模（`w_predict_mul=2.0`），稳重少虚招（`feint_rate=0.1`），出手必中。与 T1 维度 6 性格表"brain = 江湖宿老/谋主"完全对齐。

**5. 门派间关系**
- **血衣教（F8）：死敌**（道统之争，被灭门）。
- **听潮书院（F4）：同修"读"道，暗盟**（书院研习读招心法，是主角心眼修炼线所在）。
- **其余五派（F2/F3/F5/F6/F7）：或敬或忌的中立**——敬其武学正大，忌其"五势圆融"为各家专精的反面映照。

**6. 出身/仇派定位**
**主角唯一出身派**（T1 维度 3 严格一致）；**非仇派**。meta hub（镜照山·旧址）即此派的重建形态，主角闯荡即"重立残照"。

### F2. 赤锋军门（北道军阵武学）

**1. 名称 + 一句话身份**
**赤锋军门**——扼守赤锋关（T1 地理 #3）的军中武学世家，以军阵长兵、连击压制立派，是"正规军阵武学"的代表，偏"锐金"势。江湖人谓其"关上一柄枪，关下万甲兵"。

**2. 架势偏好**
**锐金 METAL（攻 OFFENSIVE，单势专精）**。叙事理由：军阵讲究"一点破面、一击贯之"，长兵器集全力于一线——锐金势的"锋锐、决绝、一击贯之"（T1 维度 5）正是军中杀人技的哲学。

**3. 招牌招式族**
- **军阵连击**（→ 近距 `STRIKE`，`required_range=CLOSE`）：近身密集连打，复用 `strike_close()`（base_damage=5、入 METAL）的概念，叙事上 = "三枪连刺、不给人喘息"。机制兼容：纯 STRIKE，无新字段。
- **压制突进**（→ `MOVE` + `STRIKE` 组合）：先 `step` 拉近距离（close distance band），再近距 STRIKE——机制上 = 现有 `TechniqueKit.step(dx,dy)` + `strike_close()` 的组合偏好，不发明新机制；叙事上 = "军阵压上、逼人至死角"。

**4. AI 性格映射**
**brute（莽将 / 嗜战的狂客）**。军门 NPC 默认 L1 碾压、不读你（`w_predict_mul=0.0`）、高侵略（`aggression=1.8`）、更随机（`top_n_mul=1.5`）——纯势大力沉，硬碰硬。与 T1 首领表"赫连铮（前军中斥候）= brute"完全对齐（赤锋军门 = 赫连铮出身来源）。

**5. 门派间关系**
- **血衣教（F8）：敌对**（血衣教渗透北道，欲夺关隘）。
- **盘根寨（F3）：相轻**（攻守之争——锐金破盘根，但寨主笑军门"只会硬冲"）。
- **朝廷：依附**（赤锋军门是正规军背景，听调不听宣）。

**6. 出身/仇派定位**
**可出身**（主角可选"边军遗孤线"——赤锋军门旁支弟子，血衣教屠边关时幸存）；**非仇派分支**。

### F3. 盘根寨（南疆固守山寨）

**1. 名称 + 一句话身份**
**盘根寨**——立于南疆密林的山寨，以横练硬功、立地生根立派，是"固守不倒"的代表，偏"盘根"势。江湖人谓其"八百寨众，任你千军，推不倒一棵老树"。

**2. 架势偏好**
**盘根 WOOD（守 DEFENSIVE，单势专精）**。叙事理由：寨中武学讲究"立地生根、任风雨不摧"（T1 维度 5 盘根势），横练硬功、桩步如磐——盘根势的"深扎盘错"正是其立派之本。

**3. 招牌招式族**
- **招架反击**（→ `STANCE_SWITCH` 守 WOOD + 反制 `STRIKE`）：先切到盘根 WOOD 占守势（守势破绽回落快，T1 维度 6），待对手攻势自叠破绽（攻势凌厉则后空）后反制一击。机制兼容：复用 `switch_to(WOOD)` + `strike_*`，守势的 `Role.DEFENSIVE` 加速回稳在现有 `Opening.decay` + stance role 已支持。
- **固守不动**（→ 原地 `STANCE_SWITCH` / 不移动）：宁可不吃伤害也不拉距离——叙事上 = "老树盘根，你退我进？"；机制上 = 高 `caution`（龟缩度，`ai_personality.gd` 字段）的性格偏好。

**4. AI 性格映射**
**brain（智将 / 守中求胜的名宿）**。盘根寨老寨主类人物默认稳重读招（`w_predict_mul=2.0`）、低侵略（可调 `aggression<1.0`）、高龟缩（`caution>1.0`）——守中求胜，待机反制。**注意**：盘根寨的 brain 与镜照门（F1）的 brain 在**架势偏好上区分**（F1 五势圆融 vs F3 单盘根），身份不雷同。

**5. 门派间关系**
- **赤锋军门（F2）：相轻**（攻守之争——盘根克厚土但畏锐金，与军门互看不上）。
- **听潮书院（F4）：盟**（一守一柔，武学相济）。
- **血衣教（F8）：敌对**（血衣教曾屠寨南疆分舵）。

**6. 出身/仇派定位**
**可出身**（主角可选"山寨流亡线"——盘根寨分舵弟子，分舵被血衣教剿灭后投奔镜照门残照）；**非仇派分支**。

### F4. 听潮书院（读招隐秘流派）

**1. 名称 + 一句话身份**
**听潮书院**——表面是海边的书院（T1 地理 #5），暗中研习"读招"心法的隐秘流派，是主角"心眼"修炼线所在。江湖人谓其"书院里的先生，比刀客更会读人"。

**2. 架势偏好**
**流水 WATER（守 DEFENSIVE，单势专精，兼修厚土 EARTH）**。叙事理由：流水势"随形成势、不争而胜、善利万物而不争"（T1 维度 5）——书院武学讲究以柔克刚、卸力渗透，不正面硬拼；兼修厚土 EARTH 作承转枢纽（读招后流转）。

**3. 招牌招式族**
- **远程渗透**（→ 远距 `STRIKE`，`required_range=FAR`）：远距低伤但稳的打击，复用 `strike_far()`（base_damage=3、入 WATER 守势）的概念——叙事上 = "气机如潮，远而不断"。机制兼容：纯 STRIKE。
- **卸力位移**（→ `MOVE` 后退/侧移）：以 `step` 拉开距离、卸掉对手攻势——叙事上 = "水来土掩，我来卸你"；机制上 = 现有 `step(dx,dy)` 的后退偏好（拉远距离档，逼对手也走远距）。

**4. AI 性格映射**
**brain（智将 / 读招大本营）**。书院 NPC 是 L2 玩家建模的最强践行者（`w_predict_mul=2.0`，死磕读你）——这正是 T1 首领表"司空弈（盲眼棋仙）= brain 强化"的来源（书院出身的血衣教书长，读招至境）。与 T1"听潮书院 = 主角心眼修炼线"一致。

**5. 门派间关系**
- **镜照门（F1）：暗盟**（同修"读"道，书院是主角心眼修炼地）。
- **盘根寨（F3）：盟**（一柔一守）。
- **血衣教（F8）：暗抗**（书院暗中护持镜照遗孤，但血衣教书长司空弈即书院叛徒）。

**6. 出身/仇派定位**
**可出身**（主角可选"书院弟子线"——明镜先生送主角入书院修心眼，与 T1 维度 3 主角"心眼成长线"咬合）；**非仇派**（但其叛徒司空弈成了血衣教书长，构成书院内部张力）。

### F5. 烈焰堂（游侠火器并修）

**1. 名称 + 一句话身份**
**烈焰堂**——游走江湖的火器与剑并修的武人堂口，以"燎原莫御"的猛烈攻势立派，偏"烈火"势。亦正亦邪，谁出钱帮谁，是江湖里的"火药桶"。

**2. 架势偏好**
**烈火 FIRE（攻 OFFENSIVE，单势专精）**。叙事理由：烈火势"燎原莫御、焚敌亦焚己、凌厉则后空"（T1 维度 5）——火器与猛火剑法皆是高风险高回报，攻势自叠破绽（守势回稳慢、攻势门户愈开），正是烈焰堂的立派哲学。

**3. 招牌招式族**
- **燎原猛攻**（→ 中距 `STRIKE`，`required_range=MID`，高 base_damage）：中距高伤打击，复用 `strike_mid()`（base_damage=4、入 FIRE 攻势）但调高伤害/破绽——叙事上 = "一剑燎原，敌我皆焚"；机制兼容：纯 STRIKE，通过 `base_damage`/`opening_dealt` 数值差异表达"猛烈"，不发明新字段。
- **火器压制**（→ 远距 `STRIKE`，`required_range=FAR`）：火铳/暗器远程压制，复用 `strike_far()` 概念但入 FIRE（而非 WATER）——叙事上 = "火器破空，凌厉无伦"。

**4. AI 性格映射**
**brute（极化莽将 / 凌厉后空的狂客）**。烈焰堂 NPC 默认高侵略（`aggression=1.8+`）、低龟缩（`caution=0.5`）、更随机（`top_n_mul=1.5`）——招招架势正确但蛮力破万法，攻势自叠破绽（风险/回报）。与 T1 首领表"雷万钧（火器剑并修）= brute 极化"完全对齐（烈焰堂 = 雷万钧出身来源）。

**5. 门派间关系**
- **夜枭镖局（F7）：交易盟**（火器买卖、黑市往来）。
- **血衣教（F8）：部分堂口暗通**（灰区——烈焰堂部分分舵被血衣教收买，成为其外围）。
- **其余正派：亦正亦邪**（谁给钱帮谁，无固定阵营）。

**6. 出身/仇派定位**
**可出身**（主角可选"游侠火器线"——烈焰堂正派堂口弟子，目睹本堂被血衣教渗透后出走）；**部分堂口为血衣教外围**（灰区，非仇派本体但有叛徒）。

### F6. 幻踪门（虚招诡谲妖人）

**1. 名称 + 一句话身份**
**幻踪门**——江湖术士、易容师、幻术名家云集的门派，以"虚招诱敌、真假难辨"立派，无固定架势偏好（以 FEINT 为核心）。江湖人谓其"你见的都是假的，真的你永远见不到"。

**2. 架势偏好**
**无固定偏好**（以 `FEINT` 为战术核心，常用**厚土 EARTH / 流水 WATER** 为表象架势——中性或守势作伪装最可信）。叙事理由：幻踪门不修一势之极，而修"骗"——虚招的表象（apparent）与实情（real）是其武学本质，架势只是骗人的画皮。

**3. 招牌招式族**
- **虚招诱敌**（→ `FEINT`，复用 `TechniqueKit.feint_strike(apparent, real_dmg, real_stance)`）：伪装打击虚招，表象用 EARTH/WATER（诱对手克土/克水），实情是 REAL 打击——机制完全复用现有 `feint_strike`，无新字段；叙事上 = "声东击西，你见我盘根，实则锐金已蓄"。
- **层层嵌套**（→ 多个 `FEINT` 连环）：虚招之上还有虚招——机制上 = 高 `feint_rate`（诡将 `0.7`）的性格偏好，连续回合出虚招；叙事上 = "表象之下还有表象"。

**4. AI 性格映射**
**trick（诡将 / 诡谲妖人大本营）**。幻踪门 NPC 默认狂出虚招（`feint_rate=0.7`）、中度读你（`w_predict_mul=1.2`）、逼你读他——与 T1 首领表"莫青娘（巫医双修）= trick / 裴渊（易容术大家）= trick 强化"完全对齐（幻踪门 = 莫青娘/裴渊的渊源所在）。

**5. 门派间关系**
- **血衣教（F8）：有渊源**（左护法莫青娘出身幻踪门旁支，但幻踪门本体中立）。
- **镜照门（F1）：无恩怨**（一修心眼一修幻术，井水不犯河水）。
- **其余门派：中立偏混乱**（幻踪门人各自行事，无统一立场）。

**6. 出身/仇派定位**
**可出身**（主角可选"江湖术士线"——幻踪门弟子，看不惯本门妖人行径而出走）；**非仇派但与仇派左护法有渊源**（灰区）。

### F7. 夜枭镖局（黑市钱货两讫）

**1. 名称 + 一句话身份**
**夜枭镖局**——江湖最大的私镖商号（T1 地理 #6），亦正亦邪，给钱就护、给更多就杀，是休整与黑市的集散地。江湖人谓其"灯笼一亮，生死两讫"。

**2. 架势偏好**
**厚土 EARTH（中 NEUTRAL，兼修流水 WATER 守）**。叙事理由：厚土势"中正不倚、承转枢纽、厚载"（T1 维度 5）——镖局武学讲究不偏不倚、亦攻亦守、以保镖为先；兼修 WATER 作逃遁卸力之用。中性架势最适合"谁也不得罪"的镖局身份。

**3. 招牌招式族**
- **位移突进**（→ `MOVE`，快速拉近距离或脱离）：镖师擅长走位突袭或保镖撤退——复用 `step(dx,dy)` 的灵活组合；叙事上 = "灯笼一晃，人已在身后"。
- **中性流转**（→ `STANCE_SWITCH` EARTH/WATER）：在厚土与流水间流转，伺机而动——机制兼容：复用 `switch_to(EARTH/WATER)`；叙事上 = "镖局老油条，见势不对先溜"。

**4. AI 性格映射**
**trick（诡将 / 黑市老油条）**。镖局 NPC 不死磕读你（`w_predict_mul≈1.0`）、出虚招骗你（`feint_rate` 中高）——与幻踪门（F6）的 trick 区分在于：幻踪门是"幻术妖人"的诡，镖局是"老油条、见风使舵"的诡。**两者性格相同但身份/架势偏好不同**（F6 无固定偏好 FEINT 核心 vs F7 厚土中性），身份不雷同。

**5. 门派间关系**
- **烈焰堂（F5）：交易盟**（火器、黑市买卖）。
- **血衣教（F8）：有买卖**（镖局给血衣教运过货，灰区）。
- **其余门派：中立**（给钱就办事，无固定敌友）。

**6. 出身/仇派定位**
**可出身**（主角可选"镖师卧底线"——夜枭镖局镖师，卧底查血衣教军火线）；**非仇派但与仇派有买卖**（灰区）。

### F8. 血衣教（仇派 · 欲统江湖）

**1. 名称 + 一句话身份**
**血衣教**——近年崛起的枭雄型新霸（T1 维度 4），信奉"五势有尊卑、武学有正统"，视镜照门的"五势圆融"为异端邪说，以"铲除邪说"为名（实为夺《五势真解》残卷）屠尽镜照门。教众血染白衣，以血祭道。

**2. 架势偏好**
**锐金 METAL + 烈火 FIRE（双攻势，信"攻势为尊"）**。叙事理由：血衣教信"势有尊卑"，攻势（锐金/烈火）为尊、守势（盘根/流水）为卑——这与其"以攻破万法、以血祭道"的极端教义一致。教中高手多修锐金或烈火，贬低守势（故与盘根寨 F3、听潮书院 F4 的守势哲学天然对立）。

**3. 招牌招式族**
- **强攻破万法**（→ 近/中距 `STRIKE`，高侵略）：教众 default 高 aggression，招招攻势——复用 `strike_close/mid` 的高侵略偏好；叙事上 = "以血祭道，攻势不绝"。
- **分堂虚招**（→ `FEINT`，部分分堂/高手用）：血衣教并非只会硬攻——左护法莫青娘（巫医）的幻踪门旁支、暗哨总管裴渊（易容）皆善虚招。复用 `feint_strike`，不同分堂/高手 feint_rate 不同。

**4. AI 性格映射**
**混合（七高手分脑 brute/brain/trick；掌门 brain+trick 合一）**。血衣教是唯一覆盖三种性格的门派——
- **brute 分堂**：右护法赫连铮、外堂宗政烈、教剑使雷万钧（莽将，硬碰硬）。
- **brain 分堂**：谋主晏九、书院长司空弈（智将，死磕读你）。
- **trick 分堂**：左护法莫青娘、暗哨裴渊（诡将，虚招百出）。
- **掌门颜无咎：brain+trick 合一**（智将底 + 虚招层）——**标 M3+ 扩展**：需扩展 `AIPersonality` 为可组合（如 `brain` 底覆写 `feint_rate`，或新建 `brain_trick_hybrid()` 工厂），M2.5 不实现。与 T1 维度 4"掌门智诡合一" + 注意事项 #1 完全一致。

**5. 门派间关系**
- **镜照门（F1）：死敌**（灭门，道统之争）。
- **七派（F2–F7）：欲统**（或压、或诱、或屠——F5 烈焰堂部分堂口被收买、F7 夜枭镖局有买卖、F6 幻踪门有渊源，余者敌对或暗抗）。
- **朝廷：抗**（血衣教不受朝廷节制，六扇门通缉）。

**6. 出身/仇派定位**
**不可出身**（= 仇派，章节首领与最终掌门来源）；**F5/F6/F7 部分外围与其有灰区往来**（给 M3 门派关系系统提供"灰区外交"玩法）。

## 与现有机制的潜在冲突 / M3+ 扩展点（给 M3 的提醒）

1. **血衣教掌门颜无咎 brain+trick 合一**：现有 `AIPersonality.brain()`/`trick()` 是单性格工厂，合一需 M3 扩展（覆写 `feint_rate` 或新建 `brain_trick_hybrid()`）。与 T1 注意事项 #1 同一问题——spec §5.1 已留口子（"权重参数可任意配"），无需改架构。**M3+ 扩展，非冲突**。

2. **门派 NPC 性格数值调参**：现有 `brain()`/`brute()`/`trick()` 三工厂数值固定（如 brain `aggression=1.0`）。M3 落地门派 NPC 时，可能需要"盘根寨 brain 低侵略"vs"镜照门 brain 中侵略"的**门派级覆写**——通过新建 `brain_defensive()`/`brain_neutral()` 工厂或在 NPC `.tres` 里覆写字段实现，不改 enum。**M3 决策，非冲突**。

3. **招牌招式落地为 .tres**：本文招牌招族是"机制概念"（如"军阵连击 = 近距 STRIKE 连发"），M3 T3（招式命名）会落成具体 `Technique` `.tres`（type/required_range/base_damage/speed/resulting_stance/opening_dealt 等字段值）。本文已确认所有概念与现有字段兼容，M3 只需填数值。**M3 落地，非冲突**。

4. **门派关系系统（M3 hub）**：本文关系拓扑（敌/盟/中立/灰区）供 M3 门派 hub 关系系统读。M3 需设计 run-state 里的 `faction_relations: Dictionary`（JSON-safe，门派 id → 关系值），以及灰区门派（F5/F6/F7 与 F8 的往来）的"外交"玩法——**M3 spec 决策，本文提供数据**。

5. **烈焰堂/幻踪门/夜枭镖局的"灰区"设定**：F5 部分堂口为血衣教外围、F6 与血衣教左护法有渊源、F7 与血衣教有买卖——这给 M3 提供"非二元敌友"的门派外交深度（主角可借灰区门派渗透血衣教），但也需 M3 设计"灰区"的玩法语义（如：灰区门派 NPC 可招募但其派系忠诚度低）。**M3+ 设计，非冲突**。
