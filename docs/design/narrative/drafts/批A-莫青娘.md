# 批A · 莫青娘（W2-2 批A · 章2 夜枭地界）

# bio（人物志正文）

莫青娘出身幻踪门旁支，学的是幻，进门先学的却是死。旁支穷，请不起先生，她认穴认毒，全从乱葬岗的白骨上来。骨头不撒谎，病走到哪一寸，骨头上都记着，这套医术，江湖里没有第二家。出师那年行医，救七个，死三个，有人送她"白骨"二字，她应下了，说骨头教出来的，姓什么不紧要。幻踪门教的是画皮惑眼，她只学了一半，另一半，她拿药补齐：药先上，招后到，你分不清自己是病了，还是伤了。血衣教来请，她只提一个条件，教里的药炉，看火的只能有她一个。灭门那夜她上过山，不为杀人，为验尸，教里要一份名录，死了几个，怎么死的。她记得清楚，也记得有一味不对：有几个死在刀下的，血是黑的，她的方子里，没有这一味。名字报了上去，这一条，她没报。如今她在夜枭地界坐堂，药香混在灯笼的暖光里，黑市上一半的止痛散出自她的炉子，教里的伤药经她的手，教里的毒，也经她的手。有人问她这药是药是毒，她说，先治病，再问病因。炉上的火，这些年倒从没熄过。

# pre（战前对白，9 句）

- 莫青娘：客人，堂里坐。先看病，还是先看生死？
- 遗照：血衣教左护法的药堂，开在镖局的灯底下。
- 莫青娘：灯是夜枭的，炉是我的，各赚各的香火。你带着一身刀伤走夜路，坐下，我瞧瞧。
- 遗照：不必。我的伤，你们教里记着账。
- 莫青娘：记得清，是好病人。听话的吃药，不听话的，吃另一副。
- 莫青娘：交手也是吃药的理。我出三招，两招是假的，哪两招，问我的炉子，别问我。
- 遗照：假招挨实一下，也就真了。
- 莫青娘：嘴硬。也罢，临了送你个药引：那夜镜照山的火，起得比令还早。
- 莫青娘：坐稳了。药气上来，人就分不清真假了。

# post_win（战后·主角胜，5 句）

- 莫青娘：好药……配错一味君，全方就翻了。
- 遗照：镜照山的账，你认多少。
- 莫青娘：我认药，不认账。救过一个该死的，折了七个该活的，这笔药不论，人论。
- 莫青娘：炉上还有半炉没揭盖的。你走的时候，替我看看火候。
- 遗照：炉盖揭不揭，由不得你了。

# post_loss（战后·主角败，4 句）

- 莫青娘：倒了？脉搏还行，死不成。
- 莫青娘：先生教出来的底子，就是经不起药。
- 莫青娘：抬到后堂去。教里说磨成粉，到我堂里，就改入药。
- 莫青娘：别抖。我的药，从来不苦。
