# 批A · 赫连铮（W2-2 批A · 章1 赤锋地界）

# bio（人物志正文）

赫连铮在赤锋关下当了十九年斥候。斥候的规矩简单：走在最前，死在最前，功劳记在别人名下。关外三百里，他认脚印、认烟、认鸦雀起落的路数，闭着眼走得回来。他那张铁面是营里的老物件，几辈斥候传下来，风沙磨亮了，到他这张就再没摘过。有人问铁面底下是什么，他说，留在关外了，懒得去取。后来北营裁了，饷断了半年，他领着十一个没处领饷的老兄弟出去讨活路，讨到血衣教门口，十一个人，一个没散。教主没跟他讲道统，只给了三样：饷、令、一个说得清的死法。他从此接教里最硬的差事，做到右护法。教里讲五势尊卑，他听不进去，军伍里没有势，只有先到和后到：你还在看他的架势，他的枪已经到了，他不挪窝则已，一挪就是压过来，压到人退无可退。镜照门那夜，山上的令归他。他领人进去，办完，出来，铁面上落了层灰，别的什么都没落。教里如今把他摆回赤锋地界，看住北道。他扎营不看风水，只看退路，营门口立两杆枪，一杆是旗，一杆是他使的。到现在没人见过他摘铁面，也没人敢问那夜山上的事。

# pre（战前对白，9 句）

- 赫连铮：站住。赤锋地界，走夜路的，先报号。
- 遗照：镜照门，遗照。来找右护法。
- 赫连铮：找对了。你的名字在令上，赏格我一直揣着，没花出去。
- 遗照：灭门那夜，你在山上。
- 赫连铮：在。山上的令归我，山下归外堂，这是那夜的排法。
- 赫连铮：你师门教你读招。我这身本事是斥候营里滚出来的，军伍里没有招，只有先到、后到。
- 赫连铮：你尽管读。读明白的时候，枪已经到了。
- 遗照：那就看看，今晚谁先到。
- 赫连铮：传我的令。一个不留。

# post_win（战后·主角胜，5 句）

- 赫连铮：好枪。……不算枪，好招。老斥候看走眼了。
- 遗照：走之前，把那夜的事说清。
- 赫连铮：可以。那夜我领的令，子时动手。火起的时候，离子时还差着两炷香。
- 赫连铮：差在哪，我查过，没查出来。这笔账记到今天。
- 赫连铮：去罢。别动我的旗，它比我先到。

# post_loss（战后·主角败，4 句）

- 赫连铮：心眼是好东西，可惜你的枪跟不上眼。
- 赫连铮：教里的令是磨成粉。军令不改。
- 赫连铮：削块无名牌，埋到关墙底下。他算阵亡，不算谋杀。
