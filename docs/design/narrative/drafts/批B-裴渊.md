# 批B · 裴渊（W2-2 批B · 章3 沉剑谷地界）

# bio（人物志正文）

裴渊这个名字，血衣教名册上只登了一个，江湖上认得这张脸的，一对也数不出来。他是幻踪门正支出身，进门头一天换了三张脸，师父看完只说了一句：这张也留不住。出师后他不在江湖上走，在江湖的缝里走，茶棚里添水的、渡口扛包的、灵堂里代哭的，看着都像他，拆开都不是。教里请他没见面，一封信送到，落款处按着一枚空指印，他回了四个字：随时候着。从此天下的暗哨归他管，天下的脸，一半打他眼前过，一半打他脸上过。影狐两个字是猎户叫出来的：狐狸再滑，雪地里总留蹄印，三县的好手追了他半个月，只追到一道影子。他的道理只有一句：人认脸，也认招，认什么，什么就是门。他把易容使在招上，出手先给你看一张脸，盘根也好，流水也好，你克的是脸；脸底下垫着真招，真招底下，还垫着假。围山前大半年，他脸上是一张洒扫杂役，在镜照山上扫地，满门的脸和路数记满两本册子，下山半个月后，山被围了。那一夜没人能靠一张脸走脱，这差事，他自认办得干净。教里的老人说见过他的真容，三个人，说出来的三张脸没有一对重样。他自己酒后会摸自己的脸，慢慢的，像在认一张生脸。有人问他累不累，他说，你们一张脸过一辈子，那才叫累。

# pre（战前对白，9 句）

- 裴渊：来了。你一路进谷，我的人一路没惊动你，这是我的待客之道。
- 遗照：你脸上这一张，是山上哪一位的。
- 裴渊：好眼力。你们三师叔的脸，我养了好几年，就等你来认。
- 遗照：把他还回去。山上的人，你要一张一张地还。
- 裴渊：还？我在山上扫了大半年地，满门的脸都在我册子上。那一夜，没一张脸走脱，差事办得干净。
- 裴渊：把话说在先头：我招招是假，假的底下，还垫着假。
- 遗照：招是假的，你这条命是真的。
- 裴渊：孩子，皮要一层一层揭。拆到第三层，你就分不清了。
- 裴渊：开戏。先猜猜，跟你说话的这一张，是谁的脸。

# post_win（战后·主角胜，6 句）

- 裴渊：这一下是真是假，我怎么分不清了。
- 遗照：剥下那张脸。死，也该以真容死。
- 裴渊：真容？让我翻翻……
- 裴渊：这张底下还有一张，再底下那张孩子的脸，我自己也几十年没看见了。
- 裴渊：山上扫地那年我没换过脸，杂役那张，就算我一张。
- 遗照：那张，我替山上的人记着。

# post_loss（战后·主角败，4 句）

- 裴渊：教里要粉，粉归他们。脸，归我。
- 裴渊：委屈一下。你这张是张好脸，我收得心安理得。

## 埋点自查

- **m7 影狐易容·千面之下（主埋之一，bio 倒数第三、二句）**：埋了"三个老人说见过真容，三张脸没有一对重样"+"他自己酒后会摸自己的脸，像在认一张生脸"。给的是线索：真容无人见过、连他本人对自己的脸也是陌生的。不给底：裴渊究竟是一个人还是几个名字共用的位置、真容什么样、千面从何而来、为何而始，全部留白；"三人对三脸"只给可疑，不坐实任何一种解释。
- **m7 影狐易容·千面之下（主埋之二，post_win 第 3-4 句）**：埋了"真容？让我翻翻……""这张底下还有一张，再底下那张孩子的脸，我自己也几十年没看见了"。给的是线索：千面之下存在过一张"最初的孩子的脸"，且已连他自己也寻不回——身份在原理上不可验证。不给底：那张脸什么样、他原本是谁、"裴渊"之名与那张脸的关系，全部悬置；死得不明不白，正是诡将死法（§2）。bio 的"摸脸如认生脸"与 post_win 的"孩子脸"同一口径，互为铺垫。
- **与既立口径零冲突核查**：围山叙事只动"人脸册"一个维度——晏九的功劳仍是围山图（几时围、哪条路断、井在哪面），裴渊的册子只记人脸与路数，两不相犯；他"下山半个月后山被围"，早于围山，不碰宗政烈"一夜没进山也没放一个人出山"、赫连铮"山上的令"与"火起早于令两炷香"（m6 时序一字未提）、莫青娘验尸与血黑之事（m8）、教主半卷开价（m2）；"教里要粉"沿用教中处置既有口径（磨成粉），是他个人的改法（脸归我），与宗政烈留全尸、莫青娘改入药路径不同。

## 声口自查

- **一句话定腔**：故人叙旧腔——句句熟络如旧识，把盯梢说成关照、把血债说成本分，层层递进"底下还有一层"，亲昵即刀。
- **区隔点**：与莫青娘同 trick 同幻踪系——她医家软腔句句带药、问句收尾，他无一句药词、以陈述代问；与晏九的赌桌生意客气（客官/注口/账）——他是私交式贴近（孩子/我候着你/待客之道），无一个交易词；与宗政烈的粗直自称老夫、赫连铮的军令短句更是全然两路。比喻系统独占：脸/皮/册子/影子/戏。
