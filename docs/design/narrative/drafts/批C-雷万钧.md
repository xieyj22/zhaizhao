# 批C · 雷万钧（W2-2 批C · 章4 血衣总坛·校场）

# bio（人物志正文）

雷万钧是烈焰堂出来的人，火器与剑并修。堂里老人说，他点火的手比握剑的手还稳。得号那一年，一股山匪夜袭堂口分舵，他单人摸进匪寨，后半夜放的火，从寨门一路烧到聚义厅，天亮才歇。山下县城望见天红了一半，县志上记了三个字的火头，江湖从此叫他焚天。后来堂里几处分舵与血衣教暗通，他没问前程，揣着一杆铳、一口剑过了山。教主给他一座校场，封教剑使。他在校场教剑，头一课教血气，往后才教招。他的道理简单：招是柴，血气是火，柴码得再齐整，不着火，也只是一堆柴。教里讲道统讲尊卑，他听不进去，也不拦别人信，他只管把剑教利索。心眼读招那一套，他更不信：你算得再精，火不认人，也不认招；铳响了就是响了，烧着谁是谁。灭门那夜他在总坛，报信的快马连夜进山门，校场上他正教到收势那一步，听完，没停课。他年纪越大，血气越旺，教里的年轻人跟他过招，多半撑不到后半场：前半场他让着，后半场他烧起来，出的招没人认得。有人问他养气的法子，他说，柴要烧到后半截，才见火色，人也一样。校场边的兵器架，剑挂得齐整，他每日亲手擦一遍。他说他在等一根柴：烧得透，也配得上他火色的那一根。

# pre（战前对白，9 句）

- 雷万钧：血衣教教剑使雷万钧。校场是我的，架子上的剑，也是我一把一把挂上去的。
- 遗照：教里的剑出自你手。灭门那夜的剑，也是。
- 雷万钧：剑教出去，怎么使是使剑人的事。我只管教得利索，不管教给谁。
- 遗照：教得利索。我师门满门的血，就是你这份利索。
- 雷万钧：见血开刃，是剑的命数，不是我的。你背着满门的仇进的这道门，火气藏不住——好一根柴。
- 雷万钧：教剑，头一课是血气。血气压不住，也不该压——烧到后半场，你就懂它的好处了。
- 雷万钧：远了我放铳，近了我出剑，你那点读招的功夫省着用：火不认人，也不认招。
- 遗照：好。今天不是你教我，是镜照门的剑，来考你的火。
- 雷万钧：口气不小，我爱听。起手罢——校场规矩：课不停，火不熄！

# post_win（战后·主角胜，5 句）

- 雷万钧：烧透了。哈哈，烧透了……
- 遗照：都烧成这样了，还笑。
- 雷万钧：这一把烧的是我自己，火色正好，笑都来不及。教了半辈子剑，临了收着这么一根，值。
- 雷万钧：往里是大殿。教主爱讲道理，讲着讲着，人就自己矮下去——你别听，只管出剑。
- 雷万钧：把我扫进风里就是，校场别占。明早……还有课。

# post_loss（战后·主角败，4 句）

- 雷万钧：收势没收住。起手那么正的一趟剑，可惜了。
- 雷万钧：招读得太精，血气跟不上。这一课，你从头上起就缺了。
- 雷万钧：你怀里那半卷，教主要去了。烧剩下的，风领走。
- 雷万钧：我校场的规矩，不埋人。一把火，扬进风里，干净。

## 埋点自查

- **无主埋义务**：风格圣经 §8 谜线分布表中雷万钧无主/辅埋点，按「没有主埋点的 boss 写人设余味」执行——bio 收笔落在「等一根配他火色的柴」，全篇柴、火色、烧透皆人设意象，不触任何谜线内容。
- **post_win 第 4 句（大殿引路）**：「教主爱讲道理，讲着讲着，人就自己矮下去——你别听，只管出剑」——只给颜无咎的行为侧写（以理压人的气场），不给灭门夜、半卷书、教主过去的任何信息，不抢 m2/m4 埋点权限，仅为终局战做声场铺垫。
- **灭门夜口径（bio）**：只写「他在总坛、快马连夜进山门报信、听完没停课」——不在场、不知情、不评火，与宗政烈（守山下）/赫连铮（领山上令）/莫青娘（事后上山验尸）的既定分工零矛盾；不碰 m6 火起时刻（快马抵坛时间与火起时刻无推导关系）。
- **trait 与 kit 预告**：pre 第 5-6 句（好一根柴一点就透／头一课是血气、烧到后半场）预告 frenzy 低血暴走；第 7 句「远了我放铳，近了我出剑」预告 kit 烈焰·破空（远距火器）+ 烈焰·燎原（中距猛攻），与 boss_config.kit 一一对应。

## 声口自查

**一句话定腔**：教剑先生的急脾气，句句是课业口令（起手、收势、头一课、校场规矩），火的意象系统独占（柴、火色、烧透、扬灰、风）。**区隔点**：与宗政烈（碑匠粗直、自称老夫、图个痛快）区隔在不自称老、不自感叹，比喻全落在火上，且带手艺人的热络；与赫连铮（军令式短句、报号传令）区隔在他的规矩是校场规矩不是军令，句式更长更吵，从不发布命令；全篇不碰碑（宗政烈）、账与筹码（晏九）、药炉火候（莫青娘）、令旗军伍（赫连铮）、易容与棋道（批B 裴渊/司空弈）。同为 brute 三人：赫连铮是杀人的莽、宗政烈是砸的莽、雷万钧是烧的莽——烈度同，质地各异。
