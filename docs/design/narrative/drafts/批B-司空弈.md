# 批B · 司空弈（W2-2 批B · 章4 血衣总坛地界）

# bio（人物志正文）

司空弈是听潮书院山长门下最年轻的讲席，一讲三十年。他的眼是看谱看坏的，一夜十局，烛读到天亮，五十岁那年，眼前的棋盘先黑了。书院要送他归乡，他不走，坐在原位又下了十年盲棋，从此院里没人再赢过他。江湖送他棋仙二字，他不认，说仙什么，我不过是听得见落子。血衣教请他没登门，只差人送来一箱各派过手旧录，他看完，自己进了总坛，做书院长。书院上下骂叛徒，他不辩。教里拿不准的对头，谱送过来，他批一个字，那人的名字就从名册上挪出去。他的武是从棋里来的，与人过手不争先手，隔两步远，一记一记像潮拍岸，你进他退，你退他缠。围山之前，镜照门的过手旧录也送到他案上，他批了三个月，一册一册批完，只剩明镜先生那一册，翻到天亮，一手也没敢落子。眼瞎之后，他听人过招，谁的呼吸乱了一拍，谁的脚跟虚了半分，落在他耳朵里都是落子声。有人问盲眼怎么读招，他说，你们看形，我听意。总坛的夜里，他有时摆一副空枰，黑白两罐都不动，他就那么坐着，像在等一手迟了很多年的棋。

# pre（战前对白，9 句）

- 司空弈：进来。门槛高三寸，抬脚。你那柄剑，剑脊添了三道新口子，是从谷里带出来的吧。
- 遗照：血衣教书院长。围山之前，镜照门的旧谱，是送到你案上的那批吧。
- 司空弈：批了三个月。每一册都批了死活，批完，山就平了。这笔账，记我名下。
- 遗照：名下也好，教里也好，都是血债。
- 司空弈：血债我不论。昨夜教里把你一路的过手送来，我复盘到三更，先说结论：好棋，坏在性子。
- 司空弈：你还没落子，我已看见。眼瞎的人，剩的就是这点本分。
- 遗照：今夜的棋，没有性子。
- 司空弈：好话。可惜说出口，就是落子。
- 司空弈：执子罢。我听着。

# post_win（战后·主角胜，5 句）

- 司空弈：输了，输得明白。前半局我手手都看得见，从你弃了性子那一步起，我看不见你了。
- 遗照：你批死的那一册册谱，条条是人命。
- 司空弈：是命，也是好棋。我批了一辈子谱，批到最上头，才碰见一点批不动的。
- 司空弈：心眼不是顶。上头还有一层，我在那一层的边上坐过一夜，没能上去。上不上去，往后看你了。
- 司空弈：谱和批注都留在案上，你带走。潮那头……替我听一声。

# post_loss（战后·主角败，4 句）

- 司空弈：停在这手上，可惜。后半局你本有一手活棋。
- 司空弈：输在性子又回来了。我读你，读的就是它。
- 司空弈：这一局我会记全谱，教里下一班学生，开课头一讲就是你。
- 司空弈：碑上刻一个"负"字就够了。下棋的人的碑，合该这样立。

## 埋点自查

- **m5 心眼之上·不可读之境（主埋，post_win 第 4 句）**：埋了"心眼不是顶。上头还有一层，我在那一层的边上坐过一夜，没能上去"。给的是线索：全书读招最强者亲口承认心眼之上另有一层境，且他本人触及边缘而未能登临——存在性由最权威的失败作证。不给底：那一层是什么、如何上去、有没有人到过、他是何时何地"坐过一夜"，全部留白；"上不上去，往后看你了"只把门指向主角，不开门。
- **m1 明镜先生·枯井遗言（辅埋，bio 第 9 句，仅 1 句）**：埋了"只剩明镜先生那一册，翻到天亮，一手也没敢落子"。只轻触批A已立边界内的事实方向——先生与棋道、心眼的渊源（先生的招谱连棋仙也读不通），与晏九 post_win"井底有话没说完"互不侵犯：此处只涉旧谱批读，不涉枯井、灭门夜现场、下落与遗言内容，未开新底。pre/post 均不再提先生，辅埋不越 bio 一步。

## 声口自查

- **一句话定腔**：棋评先生腔——每句都像批谱复盘，称招为"手"，先给结论再下判词，无寒暄无客气，瞎而不谦，冷而不厉。
- **区隔点**：与晏九同 brain 同听潮系——晏九是赌桌上的生意客气（客官/注口/开盅/账），司空弈是讲席上的判卷评点（结论/死活/复盘/批注/负），无一个交易词；盲眼听意（呼吸/脚跟/落子声）是他独有的感官层，另四人无此维度；比喻系统独占：枰/手/谱/落子/潮。
