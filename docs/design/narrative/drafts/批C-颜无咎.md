# 批C · 颜无咎（W2-2 批C · 章4 血衣总坛·大殿，终局 boss）

# bio（人物志正文）

颜无咎三个字，是立教那年才有的。在这之前，江湖上查不到这个人：没有师承，没有诨号，没有仇家。教外不是没人较过真，顺着这片空白查下去，查到最后，那些人都不大出门了。教义出自他的亲笔，写得极慢，一部经要写几年，写完当众封卷，落他的印。教众白衣，血入衣为祭，祭道，也祭他。受祭的位子只有一个，教中称呼里，他占着一个尊字。教中讲五势尊卑，攻势为尊；他案头那半卷残经上，批注写的却是圆融。有长老壮着胆问过，这两样怎么并得住，他答：经是真的，时机没到。再问，他便笑，不再开口。殿上他极少起手。起过的那一回统共三招：一招是虚的，落空的是对手；另一招，在场的老江湖认了出来，是镜照门的开蒙剑。没人敢问血衣教主为什么会镜照门的剑，他也从不打算解释。灭镜照门的令，出自他的亲笔，教中文书至今这么记。他从不谈那一夜，教中人当着他的面，连镜照两个字都少提。那半卷经他随身带了半生，页脚翻得起了毛。他为它开过价，价比山高，后来又添过一句：整个教，也可以押上去。有人问值不值，他说，半卷不是书，是半句话；人撞上半句话，余下的日子都是在等它说完。立教以来，没人见教主动过怒。只有一回。第二天，教里多了第一条教规：不许问教主的从前。

# pre（战前对白，10 句）

- 颜无咎：进来。香案上这炉香，替镜照门上了三日，今夜正好烧到头。
- 遗照：屠门的，给灭门的上香。
- 颜无咎：礼数罢了。你们讲亮势问意，我讲以血祭道，两家的规矩，今夜都用得上。
- 遗照：我带的规矩只有一条——血债，血偿。
- 颜无咎：先说一桩正经的。怀里的半卷给我，价你开：教可以散，人可以偿，我这项上人头，也列得进去。
- 遗照：满门的命，你怎么列。
- 颜无咎：列不进，所以今夜才要动手。那道令是我亲笔，印是我亲手盖的。血衣教写下的字，不劳别人来涂。
- 颜无咎：交手之后留神：你砍开的地方，会自己合上。不是术，是祭——血债这门功课，我修了一辈子。
- 颜无咎：还有，我出的手未必招招是真。你师门教过你辨假，别浪费了。
- 颜无咎：香到头了。起手罢。

# post_win（战后·主角胜，6 句）

- 颜无咎：好剑。这一式，经里没有——合眼之前，倒叫我看全了。
- 遗照：半卷，交出来。
- 颜无咎：拿去。到手也是半部。这部书拆成两半那天起，世上还没人两半都读过。
- 颜无咎：翻开之前，替它想一句：好好的经，当初为什么拆。想通了，再决定合不合。
- 颜无咎：这些话，你尽可以不信。写经的人，最会哄读经的人。
- （s 留空·旁白）香案上那半卷的封皮是新的。旧封皮贴身收在他怀里，边角磨得发亮。

# post_loss（战后·主角败，5 句）

- 颜无咎：剑是好剑。开蒙那一式，你使到最后一口气，都没走样。
- 颜无咎：半卷取下来，供回案上。隔着三尺，先这么放着罢。
- 颜无咎：你落气之前，手往剑柄上收了三回。这个死法，我从前见过一回。
- 颜无咎：见过一回，就够立一个教了。
- 颜无咎：白衣给他换上，剑搁回他怀里。经，今夜添一页——墨，他自己带来了。

## 埋点自查

- **m2 五势真解·两半之秘（主埋，bio 末段 + post_win 第 3-5 句）**：
  - bio 埋「为何要」：他为半卷开过价、价比山高（与晏九 pre「教主在桌上开过价，价开得比山高」、宗政烈 post_win「为那书什么都能舍」同口径互证），且把整个教也押得上去——他要的东西比教大；「半卷不是书，是半句话」给出动机的形状（执念于说完），不说那句话是什么。
  - bio 埋「合一是为了什么」：只给「经是真的，时机没到」——圆融之经为真、时候未到，方向是「合一有时机问题」，时机为何、合一后是什么，全部留白。
  - post_win 埋：①世上还没人两半都读过（合并无先例，代价与结果未知）；②「当初为什么拆」只提问不给答（拆分是有意之举这一方向由垂死的教主口中说出）；③紧接第 5 句他自认「写经的人，最会哄读经的人」——把上一句的方向自我标注为可疑，trick 底色兜底，读者无法当事实采信。不揭底：两半合一的具体作用、拆分的真实缘由、他真正所图，全数封存。
- **m4 血尊旧事·创教之痛（主埋，post_loss 第 3-4 句）**：「你落气之前，手往剑柄上收了三回。这个死法，我从前见过一回。见过一回，就够立一个教了。」只给痛的存在（他从前见过这样攥剑而死的人）与形状（这一眼足以让他立教——创教是对这次死亡的反动），不给内容：死者是谁、何时、与他和镜照门的关系、为何促成血衣教，一字不提。bio 侧仅给同方向的封条（立教前查无此人、第一条教规=不许问教主的从前），属存在级铺垫，不提前泄露形状。
- **既定事实核对**：bio 只认「灭镜照门的令出自亲笔、文书至今这么记、他从不谈那一夜」——不提火、不提时辰、不提山上山下分工，与 m6 既定口径（火起早于令两炷香、内情未说）零矛盾，教主知情与否维持未定；右护法管山上、外堂守山下的分工未触碰。
- **kit 咬合即埋点呼应**：bio「统共三招：一招是虚的……另一招是镜照门的开蒙剑」对应 boss_config.kit 三技（血衣·装金 FEINT／镜照·初照／血衣·血祭），他会镜照门开蒙剑不解释——正是持有半卷真解的暗写，属 m2 边界内的事实性呼应，不新增揭底。
- **trait 预告**：pre 第 8 句「你砍开的地方，会自己合上」预告 blood_drain；第 9 句「我出的手未必招招是真」预告 brain_trick_hybrid 的虚招层（血衣·装金）。

## 声口自查

**一句话定腔**：讲经人的静腔——不吼、不辩、不威胁，句面平静而信息密，威胁全部收在教义和开价里；trick 底色落实为「每句话都对，但每句话都可疑」，由他亲口自认。**区隔点**：与莫青娘（医家软腔、问句收尾）区隔在他以陈述句为主、绝不软；与晏九（赌桌腔、客气带杀）区隔在他的客气是礼数带祭、从不用注口筹码账目；与赫连铮（军令式）区隔在句长而缓、从不命令；与宗政烈（粗直自称老夫）区隔在从无自称、从无感慨；核心意象=经卷、亲笔、封卷、血祭、封皮，全系统独占，不碰碑、药、账、军令、火（雷万钧）、易容与棋道（批B）。终局分量靠「信息密而句面静」撑：他每句话都在改写前四章你信过的东西，但语气像在封一卷经。
