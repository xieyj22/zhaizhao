# 批A · 晏九（W2-2 批A · 章2 听潮地界）

# bio（人物志正文）

晏九的听涛阁临潮而开，楼下是渡口，楼上是赌桌。阁原不姓晏，是对家押上来的，连人带楼，一夜改的姓。他半辈子坐在桌后看人下注，看出一门学问：人输钱之前，先输坐相，摸牌的手一紧，这局就定了。三十岁后他把牌桌上的眼力搬进武行，与人过手从不出全力，只出够赢的那一点，动手又爱拉开身位，远远地耗，像庄家不肯先亮底牌。江湖送他"第一赌徒"四个字，他嫌绕口，说赌桌底下见。得号"笑面"，是因为他输也笑，赢越大，笑得越轻。血衣教主亲自登门设过一局，他看完骰盅就跟着走了，没人知道那局赌的什么，只知道教里从此多了个谋主。谋主不打仗，只画图、批条子，批到谁，谁家就败。江湖上寻仇的排到渡口，他不躲，添个座，倒茶，茶喝完，仇家多半就不寻了。镜照山那张图是他画的：几时围山，哪条路断，井打在哪一面，都在他笔下。有人问图上那口井画得那么细做什么，他笑而不答，只说好图不白画。教里上下都夸谋主算无遗策，他不认：算什么算，我只是坐对了桌。

# pre（战前对白，9 句）

- 晏九：客官留步。听涛阁今夜封楼，只开一张桌。
- 遗照：血衣教的谋主，亲自坐庄。
- 晏九：谋主不动手，动手的是规矩。你从赤锋一路杀到我桌前，规矩只好重开一局。
- 遗照：这一局，我押师门。
- 晏九：好注口。可惜你押错了筹码。
- 晏九：你怀里揣的那半卷东西，教主在桌上开过价，价开得比山高。
- 晏九：再说句行家话。你过关的路数我翻过账，遇强先守，得空便进，十局里七局一个模样。
- 遗照：那这一局，换个模样给你看。
- 晏九：这就对了。变得不可读，才配坐我对面。开盅。

# post_win（战后·主角胜，5 句）

- 晏九：好牌。亮得我一句嘴都插不上。
- 遗照：你们要的，从来不是我这条命。
- 晏九：聪明。镜照山的图是我画的，几时围山、哪条路断，连那口井打在哪面，都在我笔下。
- 晏九：送你句不收钱的。图交了差，那口井我又去看过一回：井底有话，先生没说完，你们镜照门欠着后半截。
- 晏九：账清了。桌上的灯留给你，替我看着它烧完。

# post_loss（战后·主角败，4 句）

- 晏九：可惜了。这副记性练到七成，输在最后一注贪了。
- 晏九：先生给的底子是好料，好料也得遇着好庄。
- 晏九：规矩不能破，输家的东西归庄家。
- 晏九：那半卷放我这儿存着，等下一个敢坐上来的，我摆给他看。

## 埋点自查

- **m1 明镜先生·枯井遗言（主埋，post_win 第 4 句）**：埋了"图交了差，那口井我又去看过一回：井底有话，先生没说完，你们镜照门欠着后半截"。给的是线索：井底存在未说完的遗言（晏九图成交差后自己去验证过，说明此事真实且有分量）。不给底：先生在哪、遗言内容、为何没说完、晏九看井时是否取走了什么，全部留白。与已揭边界（先生与枯井、灭门夜有关）只增不矛盾：宗政烈 pre 的"井里有一个"是灭门夜藏的主角，此处是晏九事后看井的发现，时间线两清。
- **m2 五势真解·两半之秘（辅埋，pre 第 6 句，≤1 句轻点）**：埋了"你怀里揣的那半卷东西，教主在桌上开过价，价开得比山高"。只把试写已揭的事实（教主手里有半卷、为它什么都舍）延伸为"教里知道另一半在主角怀里、开过价"，坐实"两半之秘"的分量；不揭合并之法、不揭真解全貌为何值得这价。post_loss 的"那半卷放我这儿存着"是败线的处置暗示，同口径。
