## 2. 比例与朝向（已定稿）

人物 24×24 头身 2.5-3 头（Q 版武人）；boss 32×32 允许 3-3.5 头+标识物；1px 墨描边外扩；抖掷(dither)≤1px 界限；单光源左上。**朝向：敌版面向左，我方版面向右。** 地形 tile 64×64 无缝（左右/上下边缘连续），明度压在人物之下。

细则：

- 24×24 人物：头部（含兜帽/巾帻）约占高 8-9px，重心落在画面中轴略偏前；脚底贴底边（留 1px 给外扩描边，人形整体离画布边缘 ≥1px）。
- 32×32 boss：头约占 9-10px；必须有 1 件标识物（兵器/法器）破出躯干轮廓，占位 ≥ 画布对角 1/2，保证剪影可辨识。
- 侧面像：面向敌方位（敌版朝左 = 鼻/刃/胸线偏 x 小侧）；双眼/目缝偏前侧。
- 单位（制式敌兵）允许镜像复用换色，但锚色与皂黑细节比例不得变。

## 3. 光照与描边

- **单光源左上 45°**：受光面在左上（TIE_L/CUO_L/JIN_L/XUE_L），背光在右下（F1/CUO_D/JIN_D/XUE_D）。禁止 pillow shading（四边均匀压暗）；禁止无来由脏点。
- **1px 墨描边外扩**：剪影外圈统一 墨#2b2b33，不占形体内空间；内部材质分界用各材质暗色细线（如 F1 分铁面/甲体），不再套墨线。兵器刃口可用 JIN_L 断线提亮代替墨线。
- 阴影 hue-shift：暗部偏冷（青/紫方向），亮部偏暖（金/橙方向），不做同色相明度平移。
- 投影不做（战棋棋格底板自带上位渲染），人物 sprite 内不画地面影子。

## 4. 抖掷（dither）

仅允许在**同 ramp 相邻两色**的过渡带用 ≤1px 界限的有序抖掷（2×2 棋盘/斜线）；禁止随机噪点抖掷、禁止跨 ramp 抖掷、禁止大面积抖掷当"材质"。人物 sprite 24/32 尺寸下原则上每处过渡 ≤6 像素总量的点缀。

## 5. 地形 tile（64×64）

- **无缝**：左右、上下边缘像素连续（生成时按环面 torus 坐标绘制；验收以 2×2 平铺目检无竖/横接缝）。
- **明度压低**：整 tile 平均明度低于同屏人物平均明度；高光只允许 F5 余烬级微亮，不得出现 METAL/JIN_L 级亮度。
- hazard（险地）：JIAO 基色为主，CUO_D/XUE_D 做暗色斑驳，裂纹走 墨 深沟 + 上缘 F5 余烬断线；裂纹为主视觉，宽度 1-2px，走向斜向优先（避免机械十字）。
- 不描墨边（tile 边缘须连续，外扩描边会破坏无缝）；形体内局部裂纹沟可用墨。

## 6. 导出规范

- PNG（RGBA，索引友好），画布即规格尺寸（boss 32×32 / 敌 24×24 / 地形 64×64），不裁切不留白框。
- alpha 二值（0 或 255）：硬边、无半透明、无对背景抗锯齿（背景可变）。地形 tile 全不透明。
- 渲染端整数倍缩放 + nearest 采样（游戏侧已有 canvas 像素化设置，资产侧保证源干净）。

## 7. 验收流程（每批必跑）

```
PYTHONUTF8=1 python tools/sprite_check.py <manifest.json> <ledger.json>
```

- manifest：`[{"path": "...", "kind": "boss|enemy|ally|hero|terrain", "anchor": [r,g,b]}]`
- 检查：尺寸 / 不透明占比 ≥0.15 / 颜色数 ≥3 / 锚色命中（TOL 24）；exit 0 = 全过。
- ledger 记 sha256_16 + 颜色数，入 batch 产物登记，防漂移。

## 8. B2 批量产图约定

- 目录：`assets/sprites/{boss,enemy,ally,hero,terrain}/`；boss 用角色名（如 `hailianzheng.png`），门派敌兵用 `F1-F8.png`，地形用语义名（如 `hazard.png`）。
- 每张图用色必须全部出自第 1 节 24 色表；锚色 = 本命门派/元素锚（boss 用其门派锚）。
- 产完逐张过验收器 + ledger 归档；人工目检剪影（1x 缩放下可辨识武器与阵营色）。
